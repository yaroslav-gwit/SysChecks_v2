In this release we're excited to make SysChecks **self-maintaining**: hosts can now update themselves straight from GitHub with `syschecks self-update`, and you can put it on autopilot with `syschecks cron autoupdate`. Updates are checksum-verified and swapped in atomically, so it's safe to run even while syschecks is busy. We've also squashed a noisy bug that let `dnf`/`yum` warnings sneak into your update reports on some RHEL-family hosts — security update counts are accurate again. Enjoy! 🚀
