SysChecks 1.3.2 is a small Alpine correction. The login banner was treating apk's expected lack of a security-only channel as a fault even when nobody had requested one, and the kernel check was reading Alpine's `vmlinuz-virt` flavor alias as though `virt` were a version.

The banner now stays quiet unless a security-only job is actually configured, while JSON remains explicit about the unsupported capability. Kernel status now reads the real installed releases from `/lib/modules`, so reboot-required checks work before and after an Alpine kernel upgrade.
